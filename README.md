## 🗂️ About this repository

This repo contains all **lab exercises** and **weekly assignments** from the **Programming 2** course, part of the **second semester (2023)** at **Digital Arts & Entertainment**, **Howest University**, **Kortrijk, Belgium**.  

It’s shared mainly for **archival purposes** — to document my development as a programmer and to keep a clear trace of how my skills evolved during the early stages of DAE’s game technology track.

> ⚠️ Like Programming 1, this repository is not production-grade code.  
> Expect experimentation, unoptimized snippets, and some “learning moments.”  
> Think of it as an **educational snapshot** of my second-semester progress.

## 🎯 Learning Goals

### LR03 — Stress & Project Management  
- Handles deadlines and workload effectively.  
- Organizes the file structure of a game project.  
- Monitors progress and seeks feedback when needed.  

### LR06 — Planning & Feasibility  
- Plans development cycles and checks technical viability of concepts.  

### LR07 — Game Development Process  
- Develops interactive 3D applications iteratively, incorporating feedback.  

### LR08 — Graphics Integration  
- Creates and integrates graphical content efficiently within real-time constraints.  

### LR09 — Programming & Problem Solving  
- Applies context-specific programming skills and game technology knowledge.  
- Understands and implements data structures and algorithms.  
- Decomposes complex problems into smaller parts.  
- Chooses solutions based on technical and directive constraints.  
- Writes clean, maintainable, and well-structured C++ code.  
- Debugs, tests, and refines solutions iteratively.  
- Utilizes engines, frameworks, and languages in a game project context.
